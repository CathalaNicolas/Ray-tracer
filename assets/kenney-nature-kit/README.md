# Kenney Nature Kit (2.1)

Low-poly outdoor meshes for the pre–Phase 2 demo room: trees, rocks, cliffs, bridges, tents, campfires. Vertex-colored OBJ (no albedo maps), so they sit inside the current 16-texture GPU cap.
