# AI and navigation

No agent moves except the player, and the player is driven by keys. The scene has no navmesh, no grid, and no path.

Solids from `docs/collision.md` are the only obstacles, and only the player tests them.

## Not built

- A navmesh or a grid.
- Pathfinding.
- Steering.
- A behavior tree or a state machine for characters.
- Sight and hearing.
- Squads, cover, and combat.
